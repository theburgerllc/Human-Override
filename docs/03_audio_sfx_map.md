# Audio + SFX Map (Premium-First)

## Core SFX categories
- ui_chimes: confirm, success, soft notification
- ui_ticks: countdown, urgency
- ui_alerts: policy change, anomaly detected
- bass_hits: impact moments (rate flips, lock denial)
- ambience: low room tone / hum (subtle)

## Signature cues
- Consent click: soft click + scan tone
- Twist reveal: bass swell (not loud), restrained alert
- Lock denial: short “deny” + low rumble
- End choice: silence drop + single tick
