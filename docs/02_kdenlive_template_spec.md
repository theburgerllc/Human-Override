# Kdenlive Template Spec (ONE CLICK)

## Project settings
- Resolution: 1080x1920 (9:16)
- FPS: 30
- Proxy clips: ON (recommended for 8GB RAM laptops)

## Track layout (recommended)
Video:
- V1: Background plates (dark gradients/noise)
- V2: UI overlays (popups/cards)
- V3: Alerts / accents (sparingly)
- V4: Text receipts/snippets
- V5: End cards

Audio:
- A1: VO
- A2: SFX
- A3: low ambience bed

## Editing rules
- Keep scenes simple: 1 primary card + 1 secondary overlay max.
- Apply heavy effects only on brief hero moments.
